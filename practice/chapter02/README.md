# Chapter 02 실습 시작 안내

Chapter 02는 다음 세 문서를 함께 사용합니다.

1. 실행 가이드: `chapter02.md`
2. 답안 템플릿: `templates/chapter02_assignment.md`
3. 공통 제출 기준: `../SUBMISSION_GUIDE.md`

```text

→ 결과 관찰
→ 나의 해석과 판단
→ 업무·분석적 의미
→ 한계/추가 확인
→ 개인 GitHub 업로드
→ chapter02/chapter02.md 파일 URL 제출
```

Chapter 02 주 제출 파일:

```text
chapter02/chapter02.md
```
