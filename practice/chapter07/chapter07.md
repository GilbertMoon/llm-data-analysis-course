# 7장 실습. 그래프로 데이터의 이야기를 보여주기

> 목표는 그래프를 많이 만드는 것이 아니라 **질문에 맞는 시각화를 선택하고, 그래프가 보여 주는 사실과 보여 주지 못하는 것을 구분하는 것**입니다.

## 공통 제출 기준
- 공통 가이드: `practice/SUBMISSION_GUIDE.md`
- Chapter별 형식: `practice/CHAPTER_SUBMISSION_MATRIX.md`
- 답안 양식: `practice/chapter07/templates/chapter07_assignment.md`
- 주 제출물: `chapter07/chapter07.ipynb`

공식 Notebook:

```text
notebooks/ch07_visualization.ipynb
```

보조 스크립트:

```text
scripts/run_visualization.py
```

## STEP 0. 제출용 Notebook 준비
공식 Notebook을 복사하여 개인 작업 파일 `chapter07/chapter07.ipynb`로 사용합니다. 외부 실행 화면은 `chapter07/images/`에 저장합니다.

## STEP 1. 시각화 질문 정의
최소 3개의 질문을 정하고 질문마다 어떤 그래프를 사용할지 이유를 작성합니다.

예:

```text
카테고리별 completed 주문 금액 비교 → 막대그래프
월별 completed 주문 금액 변화 → 선그래프
상품 가격 분포 → 히스토그램/분포 그래프
```

## STEP 2. 집계표 먼저 확인
그래프를 그리기 전에 그래프의 원본이 되는 집계표를 먼저 확인합니다.

성공 기준:
- [ ] 그래프에 사용한 데이터 범위가 명확합니다.
- [ ] completed 금액 분석이면 동일한 필터 기준을 사용합니다.
- [ ] 그래프 값과 집계표 값이 일치합니다.

## STEP 3. 막대그래프 작성과 해석
카테고리·상품 등 범주 비교 그래프를 작성합니다.

반드시 확인:
- 축 이름
- 단위
- 정렬 기준
- 상위/하위 범주
- 값의 차이가 실제로 얼마나 큰지

Notebook Markdown 셀에 `결과 관찰 → 해석 → 업무 의미 → 한계`를 작성합니다.

## STEP 4. 선그래프 작성과 해석
월별/기간별 변화를 그립니다.

확인할 것:
- 날짜 정렬
- 누락 기간
- 축 범위
- 증가/감소가 지속적인지 일시적인지

그래프가 내려갔다고 원인을 단정하지 않습니다.

## STEP 5. 분포 그래프 작성과 해석
가격, 수량 등 숫자형 변수의 분포를 확인합니다.

확인할 것:
- 중앙에 값이 몰려 있는지
- 긴 꼬리가 있는지
- 극단값 후보가 있는지
- 극단값이 오류인지 실제 값인지 추가 확인이 필요한지

## STEP 6. 그래프와 수치 교차 검증
대표 그래프 2개 이상에 대해 실제 집계 수치와 그래프가 같은 내용을 보여 주는지 확인합니다.

```text
그래프가 예쁘게 보인다
≠
그래프가 정확하다
```

## STEP 7. 오해를 줄이는 그래프 점검
다음 항목을 체크합니다.

- [ ] 축이 잘리지 않아 과장되지 않음
- [ ] 단위가 표시됨
- [ ] 범례가 필요한 경우 있음
- [ ] 색상만으로 의미를 구분하지 않음
- [ ] 제목이 실제 분석 범위를 반영함
- [ ] 표본 수/범위 차이가 있다면 해석에 반영함

## STEP 8. 스크립트 재실행
가능하면 실행합니다.

```powershell
python scripts/run_visualization.py
```

Notebook과 스크립트 결과가 같은 분석 범위를 사용했는지 확인합니다.

## STEP 9. 최종 시각화 해석
대표 그래프 3개를 선택해 다음을 작성합니다.

1. 그래프에서 직접 확인한 사실
2. 내가 중요하다고 판단한 패턴
3. 업무적으로 어떤 추가 확인이 필요한지
4. 그래프만으로 말할 수 없는 것
