# Chapter 03 실습 시작 안내

Chapter 03는 다음 세 문서를 함께 사용합니다.

1. 실행 가이드: `chapter03.md`
2. 답안 템플릿: `templates/chapter03_assignment.md`
3. 공통 제출 기준: `../SUBMISSION_GUIDE.md`

기존 `chapter03.md`의 CSV 로딩, shape·dtypes, 결측·중복, 주요 ID, 날짜 변환과 PK/FK 검증 절차는 그대로 진행합니다.

최종 제출은 실행 완료 Notebook을 사용합니다.

```text
공식 notebooks/ch03_data_overview.ipynb 복사
→ 핵심 셀 실행
→ Markdown 셀에 관찰·해석·판단·업무 의미·한계 작성
→ 개인 GitHub chapter03/chapter03.ipynb 업로드
→ 최종 Notebook 파일 URL 제출
```

Notebook 밖의 화면이 필요할 때만 `chapter03/images/`를 사용합니다.
