# Make 자동화 시나리오 가이드

## Make 자동화 개념

Make는 여러 웹 서비스와 앱을 연결해 반복 작업을 자동으로 실행하는 도구입니다. 수업에서는 복잡한 운영 자동화보다 데이터 분석 업무 흐름을 이해하는 개념 실습에 집중합니다.

## Google Drive CSV 업로드 감지 시나리오

예시 시나리오는 Google Drive 특정 폴더에 CSV 파일이 업로드되면 자동으로 다음 단계를 실행하는 흐름입니다.

1. Google Drive 모듈이 새 CSV 파일 업로드를 감지합니다.
2. 업로드된 파일 정보를 분석 서버 또는 스크립트 실행 환경에 전달합니다.
3. Python 분석 스크립트가 CSV를 읽고 기초 분석을 수행합니다.
4. 분석 결과로 보고서 파일을 생성합니다.
5. Gmail 또는 Slack으로 완료 알림을 보냅니다.

## CSV 업로드 후 보고서 발송 흐름

CSV 업로드 -> 분석 실행 -> 보고서 생성 -> 이메일 발송 순서로 구성합니다. 실제 수업에서는 전체 시스템을 완성하기보다 각 단계가 어떤 역할을 하는지 이해하고 간단한 예시 화면을 구성합니다.

## 수업 진행 안내

Make 실습은 개념 중심으로 진행합니다. 외부 계정 연결, 권한 설정, 과금 정책은 기관 환경에 따라 다를 수 있으므로 실제 운영 자동화는 별도 검토가 필요합니다.
