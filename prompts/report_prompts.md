# 보고서 프롬프트

## 분석 보고서 초안 작성 프롬프트

다음 분석 목적, 주요 결과, 그래프 설명을 바탕으로 초급 수준의 분석 보고서 초안을 작성해 주세요. 보고서는 배경, 데이터 설명, 분석 결과, 결론, 제안 순서로 구성해 주세요.

## 요약문 작성 프롬프트

다음 보고서를 5문장 이내의 경영진 요약문으로 압축해 주세요. 숫자 근거와 핵심 제안을 포함하되, 과장된 표현은 피해주세요.

## 의사결정 제안 작성 프롬프트

다음 분석 결과를 바탕으로 실행 가능한 의사결정 제안 3개를 작성해 주세요. 각 제안에는 기대 효과, 필요한 추가 데이터, 주의사항을 포함해 주세요.
