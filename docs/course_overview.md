# 과정 개요

## 과정 소개

`LLM 기반 데이터 분석 실무 입문` 과정은 데이터 분석 초보자가 Python을 기반으로 데이터 분석의 전체 흐름을 경험하고, ChatGPT/Gemini 같은 LLM을 실무 분석 보조 도구로 활용하는 방법을 익히는 15주 과정입니다.

이 과정은 단순히 pandas 문법이나 그래프 작성법만 다루지 않습니다. 하나의 온라인 쇼핑몰 데이터를 중심으로 분석 질문 만들기, 데이터 전처리, EDA, 시각화, 간단한 머신러닝, LLM 기반 코드 생성과 검증, 외부 데이터 수집, 보고서 작성, 자동화 아이디어까지 연결합니다.

강의안은 전통적인 수업 교재 형식보다는 일반 ebook처럼 읽히는 구성을 지향합니다. 각 장은 개념 설명과 예시, 실습 방향, 프로젝트 확장 흐름을 함께 담아 수업 중 자료와 복습용 자료로 모두 활용할 수 있도록 구성합니다.

## 대상 학습자

- Python 데이터 분석을 처음 배우는 학습자
- pandas, 시각화, 간단한 머신러닝까지 한 흐름으로 경험하고 싶은 학습자
- ChatGPT 또는 Gemini를 분석 질문 생성, 코드 작성, 결과 해석, 보고서 작성에 활용해 보고 싶은 학습자
- 공공데이터/API/크롤링을 통해 외부 데이터를 수집하는 기본 흐름을 익히고 싶은 학습자
- 분석 결과를 보고서와 자동화 흐름으로 연결해 보고 싶은 학습자

## 과정 목표

이 과정을 마치면 다음과 같은 흐름을 경험할 수 있습니다.

- CSV 데이터를 읽고 데이터 구조를 파악합니다.
- pandas로 필터링, 정렬, 집계, 전처리를 수행합니다.
- matplotlib과 seaborn으로 기본 그래프를 만들고 해석합니다.
- 분석 질문과 가설을 만들고 EDA 흐름을 구성합니다.
- scikit-learn으로 간단한 회귀/분류 모델을 학습하고 평가합니다.
- LLM에게 분석 질문, 코드 초안, 오류 해결, 해석 문장, 보고서 초안을 요청하고 결과를 검증합니다.
- 공공데이터, 네이버 API, 기본 크롤링을 통해 외부 데이터를 수집하는 방식을 이해합니다.
- 분석 결과를 Word/PDF 보고서와 자동화 아이디어로 연결합니다.

중간 프로젝트는 샘플 쇼핑몰 데이터를 활용한 EDA와 시각화 중심으로 진행합니다. 기말 프로젝트는 여기에 머신러닝, LLM 활용, 보고서 작성, 자동화 아이디어를 더해 하나의 실무형 분석 결과물로 확장합니다.
