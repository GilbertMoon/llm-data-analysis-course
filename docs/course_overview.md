# 과정 개요

## 과정 개요

LLM 기반 데이터 분석 실무 입문 과정은 데이터 분석 초보자가 Python과 LLM을 함께 사용해 분석 업무의 전체 흐름을 경험하도록 설계된 15주 강의입니다.

## 대상 학습자

- Python 데이터 분석을 처음 배우는 학습자
- ChatGPT 또는 Gemini를 실무 분석 보조 도구로 사용해 보고 싶은 학습자
- 보고서 작성과 자동화까지 연결되는 분석 흐름을 익히고 싶은 학습자

## 학습 목표

- CSV 데이터를 읽고 전처리할 수 있습니다.
- pandas로 집계와 탐색적 분석을 수행할 수 있습니다.
- matplotlib, seaborn으로 기본 그래프를 만들 수 있습니다.
- LLM에게 분석 질문, 코드, 인사이트, 보고서 초안을 요청하고 결과를 검토할 수 있습니다.
- 분석 결과를 Word 보고서와 자동화 흐름으로 연결할 수 있습니다.

## 사용 도구

- Python, Jupyter Notebook
- pandas, numpy, matplotlib, seaborn
- ChatGPT, Gemini, Gemini API
- python-docx
- Make
- Airflow, Docker
- GitHub
