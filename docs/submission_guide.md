# 제출 가이드

## LMS 제출 방식

LMS 과제 게시판에 제출 파일 또는 GitHub URL을 업로드합니다. 제출 전 노트북이 위에서 아래로 실행되는지 확인합니다.

## GitHub 제출 방식

본인 GitHub 저장소에 실습 결과를 push한 뒤 저장소 URL 또는 Pull Request URL을 제출합니다.

## 제출 파일 목록

- 주차별 Jupyter Notebook
- 분석 결과 그래프 이미지
- Word 또는 PDF 보고서
- 프롬프트 로그 문서
- 프로젝트 발표 자료가 있는 경우 별도 첨부

## 프롬프트 로그 제출 안내

LLM을 사용한 경우 어떤 질문을 입력했고, 어떤 답변을 분석에 반영했는지 기록합니다. 프롬프트 로그는 결과의 신뢰성과 재현성을 확인하기 위한 자료입니다.

## LLM 사용 시 주의사항

- API Key와 개인정보를 입력하지 않습니다.
- LLM이 생성한 코드는 직접 실행하고 결과를 검증합니다.
- 데이터에 근거하지 않은 과장된 해석을 보고서에 쓰지 않습니다.
- LLM 답변을 그대로 복사하지 말고 본인의 분석 맥락에 맞게 수정합니다.
