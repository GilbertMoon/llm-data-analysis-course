# 15주차 강의 계획

이 문서는 `LLM 기반 데이터 분석 실무 입문` 과정의 15주 흐름을 요약한 주차별 계획입니다. 전체 구성은 일반 ebook형 강의안과 실습 노트북을 함께 활용하는 방식으로 운영합니다.

## 전체 흐름

```text
데이터 분석 개요와 환경 준비
→ 데이터 구조 이해
→ pandas 기초
→ 전처리
→ EDA와 시각화
→ 머신러닝 기초
→ 중간 프로젝트
→ 회귀/분류 실습
→ LLM 기반 분석 보조
→ 외부 데이터 수집
→ 자동화와 파이프라인
→ 기말 프로젝트
```

## 주차별 계획

| 주차 | 주제 | 주요 실습/활동 |
| --- | --- | --- |
| 1 | AI 기반 데이터 분석 개요 및 개발 환경 설정 | 데이터 분석 흐름 이해, LLM 활용 방향 정리, Python/VS Code/Jupyter/GitHub 환경 준비 |
| 2 | 데이터 구조 이해 | CSV 읽기, 행/열 구조 확인, 컬럼 의미 파악, 데이터 타입 점검 |
| 3 | pandas 기초 | DataFrame, 컬럼 선택, 조건 필터링, 정렬, 기본 집계 |
| 4 | 데이터 전처리 | 결측치, 중복, 이상치, 날짜 처리, 분석용 데이터 정리 |
| 5 | EDA 질문 만들기 | 업무 질문을 분석 질문으로 변환, 가설 설정, 그룹별 비교 설계 |
| 6 | 데이터 시각화 | 막대그래프, 선그래프, 분포 시각화, 그래프 해석 문장 작성 |
| 7 | 머신러닝 기초 | 지도학습, 분류/회귀, feature/target, train/test split, 평가 지표 이해 |
| 8 | 중간 프로젝트 | 샘플 데이터 기반 EDA, 전처리, 시각화, 기초 인사이트 제출 |
| 9 | 회귀 분석 실습 | 매출/가격 예측, Linear Regression, RandomForestRegressor, MAE/RMSE/R² |
| 10 | 분류 분석 실습 | 주문 취소/구매 여부 예측, Logistic Regression, RandomForestClassifier, accuracy/precision/recall |
| 11 | LLM을 활용한 분석 프롬프트 | 데이터 설명, 분석 질문 생성, 전처리/시각화/ML 코드 생성 프롬프트 작성 |
| 12 | LLM 코드 생성과 검증 | LLM 생성 코드 검토, 오류 수정, 결과 검증, 보고서 초안 작성 |
| 13 | 외부 데이터 수집 | 공공데이터, 네이버 API, 기본 크롤링 개념 및 활용 |
| 14 | 분석 자동화와 파이프라인 | Make/n8n 자동화 개념, Airflow DAG 구조 이해, 기초 파이프라인 실습 |
| 15 | 기말 프로젝트 | EDA + 시각화 + ML + LLM 활용 + 자동화 아이디어 발표 |

## 중간 프로젝트

8주차에 진행합니다. 제공된 샘플 데이터로 분석 질문을 만들고, 전처리, 집계, 시각화, 인사이트를 포함한 노트북을 제출합니다. 머신러닝은 필수 항목이 아니라 선택 확장 항목으로 둘 수 있습니다.

권장 제출물은 다음과 같습니다.

- 분석 질문 3개 이상
- 전처리 과정이 포함된 Jupyter Notebook
- 주요 집계 결과
- 시각화 그래프 2개 이상
- 데이터에 근거한 인사이트 요약
- LLM을 사용한 경우 간단한 프롬프트 로그

## 기말 프로젝트

15주차에 진행합니다. 중간 프로젝트보다 확장된 형태로, 분석 노트북, 프롬프트 로그, 보고서 파일, 머신러닝 모델링 결과, 자동화 아이디어를 함께 제출합니다.

권장 제출물은 다음과 같습니다.

- 최종 분석 노트북
- EDA 및 시각화 결과
- 회귀 또는 분류 모델 중 1개 이상
- 모델 평가 결과와 해석
- LLM 활용 프롬프트 로그
- Word/PDF 형식의 분석 보고서
- Make, n8n, Airflow 중 하나를 활용한 자동화 아이디어 또는 간단한 설계안
