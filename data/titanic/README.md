# Titanic data

이 폴더는 Titanic AI 분석 실습에 사용할 데이터 파일을 배치하는 위치입니다.

예정 경로:

```text
data/titanic/train.csv
```

## 현재 상태

`train.csv`는 아직 이 저장소에 추가하지 않았습니다. **검증된 출처와 재배포 가능 여부를 확인한 뒤** 실제 실습 파일을 추가합니다.

데이터 파일이 없을 때 임의의 Titanic 수치나 가짜 CSV를 만들어 실습 결과처럼 사용하지 않습니다.

파일이 추가된 뒤에는 다음 항목을 이 문서에 기록합니다.

- 원본 출처
- 원본 URL 또는 공식 페이지
- 라이선스/재배포 조건
- 파일 SHA 또는 버전 식별 정보
- 행/열 수 검증 결과
- 실제 컬럼 목록
- Target 컬럼 확인 결과

학생 Notebook은 실제 파일을 읽은 뒤 얻은 결과만 분석 근거로 사용합니다.
