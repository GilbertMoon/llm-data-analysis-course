## 5. 전반적 평가

ch12는 Chapter 8과 Chapter 11의 결과물을 하나의 Markdown 보고서로 취합하는 장이므로, 앞 장보다 파일 의존성이 큽니다. 따라서 가장 중요한 수정은 **Notebook 파일명 통일**, **핵심 입력 파일 누락 시 명확한 안내**, **그래프 이미지 파일 존재 여부 확인**입니다.

반면 `to_csv()` 인코딩, `base_dir` 자동 감지 고도화, Markdown 파일의 `utf-8-sig` 저장, 용어 정리 추가는 교재 품질을 높이는 데 도움이 되지만 필수 오류로 보기는 어렵습니다. 특히 Markdown은 UTF-8 저장이 자연스럽기 때문에 CSV와 동일하게 BOM 포함 저장을 강제할 필요는 없습니다.

따라서 ch12 수정은 실행 안정성과 제출 결과물 품질에 직접 영향을 주는 항목 위주로 우선 반영하는 것이 적절합니다.
