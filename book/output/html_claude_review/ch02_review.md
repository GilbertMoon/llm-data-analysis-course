### [1-2] GitHub 계정 생성 안내 부족

**판단**

### [1-3] Jupyter Notebook에서 `.venv` 커널 선택 안내 없음

**판단**  
타당합니다. 가상환경에 패키지를 설치했더라도 Notebook 커널이 다른 Python 환경을 사용하면 패키지 인식 오류가 발생할 수 있습니다.

**권장 수정 방향**

- 커널이 `.venv`인지 확인
- `.venv`가 보이지 않을 때는 커널 등록이 필요할 수 있다는 안내

---

### [1-4] `.env.example` → `.env` 파일 생성 절차 없음

**판단**  
타당합니다. 원문은 `.env.example`과 `.env`의 차이를 설명하지만, 실제 `.env` 파일을 어떻게 만드는지 절차가 부족합니다.

**권장 수정 방향**  
섹션 3.9에 다음 내용을 추가합니다.

- `.env.example`을 복사해 `.env` 파일을 만든다.
- `.env` 파일에는 실제 수업용 환경값을 입력한다.
- `.env` 파일은 GitHub에 올리지 않는다.

---

### [1-5] commit/push 실습 절차 없음

**판단**  
타당합니다. 학습 목표와 실습 흐름에는 commit/push가 포함되어 있는데, 실제 절차가 본문에 없습니다. 과제 제출과 연결되는 부분이므로 필수 보완에 가깝습니다.

**권장 수정 방향**

## 5. 반영 제외 항목

### [4-1] PowerShell 섹션에서 `/` 경로 사용 문제

**판단**  
`python scripts/generate_sample_data.py`는 Windows PowerShell에서도 일반적으로 동작합니다. Windows에서는 반드시 `scripts\generate_sample_data.py`로 써야 한다는 지적은 과도합니다.

**처리**  
필수 수정에서 제외합니다. 필요하면 “본 교재에서는 운영체제 간 호환성을 위해 `/` 표기를 주로 사용한다” 정도의 설명만 선택적으로 추가합니다.

---

### [4-2] `Path` import 중복 문제

**판단**  
Jupyter Notebook에서는 셀을 독립적으로 실행할 수 있으므로 예제 코드마다 필요한 import를 반복하는 것이 오히려 초보자에게 안전합니다. 중복 import는 오류가 아닙니다.

**처리**  
반영 제외합니다.

---

### [4-3] Windows에서 `python3` 명령 가능성 안내

**판단**  
초보자 교재에서는 Windows는 `python`, macOS/Linux는 `python3`으로 구분하는 현재 구조가 더 명확합니다. Windows에서도 `python3`일 수 있다는 예외를 강조하면 오히려 혼란을 줄 수 있습니다.

**처리**  
반영 제외합니다.
