### [1-3] `~` 연산자와 `.isin()` 함수 미설명 — [섹션 5.14]

**문제**  
섹션 5.14의 핵심 코드:
```python
invalid_customers = orders[~orders["customer_id"].isin(customers["customer_id"])]
```
비전공자에게 `~`(NOT 연산), `.isin()`(포함 여부 확인), 불리언 인덱싱이 모두 한 줄에 등장한다. 각 연산이 무엇을 의미하는지 설명이 전혀 없어 코드를 따라 치더라도 의미를 이해하지 못한다.

**수정 지시**  
해당 코드 앞에 단계별 설명을 추가한다:

```python
# .isin()은 특정 값들이 포함되어 있는지 True/False로 반환합니다
# 예: [True, False, True, True, ...]
mask = orders["customer_id"].isin(customers["customer_id"])

# ~는 True/False를 반대로 뒤집습니다 (NOT 연산)
# customers에 없는 customer_id만 남깁니다
invalid_customers = orders[~mask]

print("customers에 없는 customer_id 수:", len(invalid_customers))
```

또한 `.isin()`의 개념을 한 줄로 설명한다:
```
.isin([값 목록])은 "이 값들 중 하나에 포함되는가?"를 확인하는 함수입니다.
엑셀의 VLOOKUP이나 MATCH 함수와 비슷한 역할을 합니다.
```

### [1-7] `describe()` 표의 `std`(표준편차) 개념 설명 없음 — [섹션 5.15, 섹션 7]

**문제**  
`describe()` 결과 항목 표에 `std`가 포함되어 있지만, 표준편차가 무엇인지 비전공자에게 설명이 없다. 나머지 항목(count, mean, min, max)은 직관적으로 이해할 수 있지만, `std`와 사분위수(25%, 50%, 75%)는 추가 설명이 필요하다.

**수정 지시**  
섹션 5.15의 `describe()` 항목 표에 설명을 보강한다:

| 항목 | 의미 | 해석 팁 |
|------|------|---------|
| count | 값의 개수 | 결측치 제외 |
| mean | 평균 | 이상치에 영향을 받음 |
| std | 표준편차 | 값이 평균에서 얼마나 퍼져 있는지. 클수록 데이터 편차가 큼 |
| min | 최솟값 | 극단적으로 작은 값이 있으면 이상치 의심 |
| 25% | 1사분위수 | 하위 25% 지점의 값 |
| 50% | 중앙값(중위수) | 전체 데이터의 정중앙 값. 평균과 크게 다르면 치우침이 있음 |
| 75% | 3사분위수 | 상위 25% 지점의 값 |
| max | 최댓값 | 극단적으로 큰 값이 있으면 이상치 의심 |
