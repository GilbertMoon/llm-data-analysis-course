### [1-1] 수업 시간 합계와 본문 불일치 — [수업 시간 구성 표]

**문제**  
수업 시간 구성 표의 기본 항목 합계는 330분, 즉 약 5시간 30분입니다. 그러나 본문은 “기본 수업은 약 3시간”이라고 설명합니다. 연습 문제 60~90분까지 포함하면 전체 운영 시간은 더 길어지므로, 현재 문장은 실제 수업 운영 시간과 맞지 않습니다.

**수정 권장**  
본문을 다음 취지로 수정하는 것이 적절합니다.

```text
기본 수업은 약 5시간 30분을 기준으로 구성되어 있습니다. 연습 문제, 인사이트 카드 작성, 발표용 문장 작성, LLM 해석 검증까지 포함하면 6~7시간 분량으로 확장할 수 있습니다.
```

또는 실제 3시간 수업으로 운영하려면 시간표의 각 활동 시간을 줄여야 합니다.

또한 Chapter 8을 먼저 실행하지 않은 학습자는 파일을 찾지 못해 실습 초반에 막힐 수 있습니다.

**수정 권장**

```text

```

가능하면 파일 존재 여부 확인 안내도 간단히 추가합니다.

```python
required_files = [
    report_dir / "ch08_category_sales.csv",
    report_dir / "ch08_monthly_sales.csv",
    report_dir / "ch08_customer_sales.csv"
]

missing_files = [path.name for path in required_files if not path.exists()]
if missing_files:
    raise FileNotFoundError(
        f"필요한 Chapter 8 결과 파일이 없습니다: {missing_files}. "
        "notebooks/ch08_midterm_project.ipynb를 먼저 실행하세요."
    )
```

### [1-4] `top_customer` 변수 선언 후 미사용 — [섹션 5.7]

**문제**  
섹션 5.7에서 `top_customer = customer_sales_sorted.iloc[0]`를 선언하지만, 이어지는 해석 문장에서는 이 변수를 사용하지 않습니다. 코드 실행에는 문제가 없지만, 초보자는 “왜 추출했는데 쓰지 않는가?”라고 혼란스러울 수 있습니다.

**수정 권장**  
두 가지 중 하나로 정리합니다.

1. `top_customer`를 실제 문장에 활용한다.
2. 사용하지 않을 변수라면 선언을 제거한다.

예시는 다음 방향이 적절합니다.

```python
top_customer = customer_sales_sorted.iloc[0]
top_customer_id = top_customer["customer_id"]
top_customer_sales = top_customer["total_sales"]

customer_interpretation = f"""
구매 금액 기준 상위 고객은 고객 ID {top_customer_id}이며,

주문 횟수와 평균 주문 금액을 함께 확인해야 합니다.
"""
```

### [2-2] `diff()`와 `pct_change()` 첫 행 NaN 설명 — [섹션 5.6]

**판단**  
`diff()`와 `pct_change()`는 이전 행과 비교하므로 첫 행은 NaN이 됩니다. 초보자에게는 설명이 있으면 좋지만, 코드 오류는 아닙니다.

**보완 방향**  
계산 직후 다음 취지의 문장을 추가합니다.

```text
첫 번째 월은 이전 월과 비교할 값이 없으므로 sales_change와 sales_change_ratio가 비어 있을 수 있습니다. 이는 오류가 아니라 비교 기준이 없다는 뜻입니다.
```

### [2-3] 취소 주문 포함 여부 안내 — [섹션 5.2, 5.3, 7.4]

원문은 이미 “취소 주문이 매출 계산에 포함되어 있다면 실제 매출이 과대 계산될 수 있다”고 경고합니다. 따라서 필수 오류는 아니지만, Chapter 8 결과 파일을 그대로 사용하는 구조이므로 ch08에서 취소 주문을 어떻게 처리했는지 확인하라는 안내를 추가하면 좋습니다.

**보완 방향**

```text
이 장의 매출 해석은 Chapter 8에서 저장한 결과 파일을 기준으로 합니다. Chapter 8에서 취소 주문을 제외했는지, 포함했는지에 따라 매출 해석이 달라질 수 있습니다.
```

## 5. 전반적 평가

Chapter 11은 이 교재 전체에서 “분석 결과를 어떻게 읽고 설명할 것인가”를 다루는 핵심 장입니다. 관찰, 해석, 가설, 인사이트, 실행 제안을 구분하는 구조는 매우 적절하며, LLM이 만든 해석 문장을 안전한 문장으로 바꾸는 흐름도 교육적으로 좋습니다.
