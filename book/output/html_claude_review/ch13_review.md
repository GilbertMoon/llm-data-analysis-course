### [1-1] 수업 시간 합계와 본문 불일치 — [수업 시간 구성 표]

**문제**  
수업 시간 구성 표의 본 실습 항목 합계는 연습 문제 60~90분을 제외해도 다음과 같습니다.

| 구성 | 시간 |
|---|---:|
| 반복 분석 업무 자동화 개념 이해 | 30분 |
| Make 기본 구조 이해 | 35분 |
| 자동화 대상 업무 정의 | 35분 |
| Python 분석 산출물 준비 | 40분 |
| Google Drive 기반 파일 전달 흐름 구성 | 45분 |
| Gmail 보고서 발송 자동화 | 45분 |
| Google Sheets 처리 로그 기록 | 40분 |
| 오류 처리와 검증 체크리스트 작성 | 40분 |
| **합계** | **310분** |

즉, 기본 수업 분량만 약 5시간 10분입니다. 그런데 본문에는 “기본 수업은 약 3시간을 기준으로 구성되어 있습니다”라고 되어 있어 학습자와 강사가 실제 운영 시간을 다르게 이해할 수 있습니다.

**수정 방향**  
다음 중 하나로 정리하는 것이 좋습니다.

- 방법 A: 본문을 “기본 수업은 약 5시간을 기준으로 구성되어 있습니다”로 수정합니다.
- 방법 B: 표의 각 활동 시간을 줄여 총합을 180분 내외로 재편성합니다.
- 방법 C: 3시간 수업안과 5시간 확장 수업안을 분리합니다.

**권장 수정 문장**

```markdown
기본 수업은 약 5시간을 기준으로 구성되어 있습니다. 시간이 제한된 경우에는 Make 실제 설정 실습을 일부 축소하고, 자동화 설계표와 검증 체크리스트 작성 중심으로 3시간 내외로 운영할 수 있습니다.
```

**수정 방향**

**권장 수정 문장**

```markdown

```

또는 코드 출력 메시지를 다음 방향으로 보완합니다.

```python
missing_files = [file for file in automation_files if not file.exists()]

if missing_files:
    print("다음 파일이 없습니다. Chapter 12 보고서 생성 실습을 먼저 실행하세요.")

    print("모든 자동화 대상 파일이 준비되었습니다.")
```

### [2-1] `to_csv()` 저장 시 인코딩 안내 — [섹션 7.2, 7.3, 7.4, 7.5, 7.8]

**재검토 결과**  
Claude가 지적한 것처럼 여러 CSV 저장 코드에 `encoding` 옵션이 없습니다. 다만 이 문제는 코드 실행 자체를 막는 오류라기보다, Windows Excel에서 한글이 깨질 수 있는 호환성 문제에 가깝습니다. 따라서 필수 수정이 아니라 보완 권장으로 낮추는 것이 적절합니다.

**보완 방향**  
학생이 Excel에서 CSV를 열 가능성이 높다면 `utf-8-sig`를 권장합니다.

```python
make_validation_checklist.to_csv(
    report_dir / "ch13_make_validation_checklist.csv",
    index=False,
    encoding="utf-8-sig"
)
```

본문에는 다음 문장을 추가하면 충분합니다.


### [3-1] `write_text(encoding="utf-8")`을 `utf-8-sig`로 강제 변경 — [섹션 7.6, 7.7]

**재검토 결과**  
Markdown과 텍스트 파일 저장에서 UTF-8은 표준적인 선택입니다. Windows 일부 도구에서 BOM 없는 UTF-8을 잘못 표시할 수는 있지만, 최근 환경에서는 대부분 정상 처리됩니다. 따라서 `utf-8-sig`를 필수로 강제할 필요는 없습니다.

**정리**  
반영한다면 다음 정도의 주석 안내면 충분합니다.

```markdown
Windows 메모장에서 한글이 깨지는 경우 `encoding="utf-8-sig"`로 저장할 수 있습니다.
```

## 5. 전반적 평가

Chapter 13은 Python 분석 결과를 Make 자동화 흐름으로 연결하는 장으로, 후반부 실무 자동화 파트의 핵심입니다. Python과 Make의 역할을 분리한 설명, Google Drive → Gmail → Google Sheets 흐름, 자동화 검증 체크리스트는 실무형 교재로서 방향이 좋습니다.

다만 이 장은 외부 서비스 계정, 권한, 파일 동기화, 이메일 발송이 연결되므로 학생이 막힐 수 있는 지점이 많습니다. 따라서 코드 문법보다 **사전 준비**, **파일 존재 확인**, **테스트 수신자 사용**, **오발송 방지**, **로그 확인** 안내가 중요합니다.

우선적으로는 Chapter 12 산출물이 없을 때의 대응 안내와 수업 시간 불일치를 수정하고, 그 다음 Google Drive/Make 계정 준비 안내를 보완하는 순서가 가장 적절합니다.
