## 1. 필수 수정으로 유지할 항목

### [필수-1] Notebook 파일명 불일치

**판단**: 타당합니다.

본문의 Notebook 경로와 실제 저장소의 Notebook 파일명이 다르면 학생이 파일을 찾지 못할 수 있습니다. 실제 저장소 기준으로 `notebooks/ch04_pandas_basic.ipynb` 또는 현재 존재하는 파일명과 본문을 반드시 통일해야 합니다.

---

### [필수-2] `how="left"`와 `how="inner"` 차이 설명 보완

**판단**: 타당합니다.

Chapter 4는 `merge()`를 실제 매출 분석에 사용하는 장입니다. `how="left"`를 사용한다는 문장만으로는 초보자가 병합 결과의 행 수 변화나 결측치 발생을 이해하기 어렵습니다.

**권장 보완 방향**

- `left`: 왼쪽 DataFrame의 행을 보존하고, 오른쪽에 매칭이 없으면 결측치가 생김
- `inner`: 양쪽 모두에 존재하는 키만 남김
- `outer`: 양쪽 전체 키를 모두 보존함
- `right`: 오른쪽 DataFrame의 행을 보존함

`order_items` 기준으로 상품 정보를 붙일 때는 주문 상세 행을 보존해야 하므로 `how="left"`가 적절하다는 설명을 추가하는 것이 좋습니다.

---

### [필수-3] `agg()` named aggregation 문법 설명 보완

**판단**: 타당합니다.

`agg(새컬럼명=(원본컬럼명, 집계함수))` 형식은 초보자에게 낯설 수 있습니다. 상품별·월별·고객별 집계에서 반복 사용되므로 처음 등장하는 위치에 설명을 추가하는 것이 좋습니다.

**권장 보완 방향**

- 왼쪽 이름은 새로 만들어질 결과 컬럼명
- 첫 번째 값은 집계할 원본 컬럼명
- 두 번째 값은 사용할 집계 함수
- 자주 쓰는 함수는 `sum`, `mean`, `count`, `nunique`, `min`, `max`

---

### [필수-4] `dt.to_period("M").astype(str)` 설명 보완

**판단**: 타당합니다.

월별 매출 분석에서 날짜 컬럼 처리는 핵심입니다. 날짜 타입 변환 후 월 단위 컬럼을 만드는 코드에는 `.dt`, `to_period("M")`, `astype(str)`가 함께 사용되므로 간단한 단계별 설명이 필요합니다.

**권장 보완 방향**

- `.dt`: 날짜 타입 컬럼에서 날짜 속성에 접근할 때 사용
- `to_period("M")`: 날짜를 연-월 단위로 변환
- `astype(str)`: 결과를 문자열 형태로 변환

---

### [필수-5] `nunique()`와 `count()` 차이 설명 보완

**판단**: 타당합니다.

월별 주문 수나 고객별 주문 횟수를 계산할 때 `order_id`는 주문 상세 행에 반복될 수 있습니다. 이때 `count()`를 쓰면 주문 수가 아니라 주문 상세 행 수가 계산될 수 있으므로 `nunique()`를 사용하는 이유를 설명해야 합니다.

---

### [필수-6] Series와 DataFrame 차이 설명 보완

**판단**: 대체로 타당합니다.

원문에는 “컬럼을 하나만 선택하면 Series가 됩니다”라는 문장이 있지만, Series가 무엇인지 짧은 설명은 부족합니다. Chapter 4가 pandas 기본 분석 장이므로 간단한 비교 설명을 추가하는 것이 좋습니다.

**권장 보완 방향**

- Series: 하나의 컬럼 또는 행으로 구성된 1차원 데이터
- DataFrame: 여러 컬럼으로 구성된 2차원 표

## 5. 정리

Chapter 4는 pandas 기본 분석의 핵심 장이므로, `merge()`, `groupby()`, `agg()`, 날짜 처리, 주문 수 계산 방식은 반드시 명확히 설명하는 것이 좋습니다.

다만 Claude 리뷰 중 일부는 다음 이유로 과도했습니다.

1. 수업 시간 합계 계산이 원문 표 전체를 반영하지 않았습니다.
2. 경로 자동감지 코드는 편의 기능이지 필수 수정은 아닙니다.
3. `to_csv()` 저장 코드가 없다는 지적은 원문과 맞지 않습니다.
4. 용어 정리, ch03 연계, 연습문제 채점 기준은 교재 품질을 높이는 보완이지만 필수 오류는 아닙니다.

따라서 실제 본문 수정 시에는 필수 항목을 우선 반영하고, 나머지는 교재 전체 스타일과 분량을 고려해 선택적으로 반영하는 것이 적절합니다.
