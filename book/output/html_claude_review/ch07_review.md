```text
1. plt.figure()
2. 그래프 작성
3. 제목/축/눈금 정리
4. plt.tight_layout()
5. plt.savefig(...)
6. plt.show()
```

**수정 방향**

```text
그래프를 이미지 파일로 저장할 때는 일반적으로 `plt.savefig()`를 `plt.show()`보다 먼저 실행합니다. 화면 출력 전에 저장해야 빈 이미지가 저장되는 문제를 줄일 수 있습니다.
```
