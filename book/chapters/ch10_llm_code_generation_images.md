# Chapter 10 이미지 생성 프롬프트

LLM 기반 데이터 분석 실무 입문 교재의 Chapter 10 “LLM을 활용한 코드 생성과 검증”에 사용할 교육용 인포그래픽 이미지를 생성해 주세요.

전체 이미지 스타일은 다음 기준을 따릅니다.

* 한국어 교재용 이미지
* 16:9 비율
* 흰색 배경
* 네이비/블루 계열 중심
* 깔끔한 교육용 슬라이드 스타일
* LLM, pandas, 코드 생성, 코드 리뷰, 검증, 오류 수정 흐름을 직관적으로 표현
* 너무 많은 텍스트는 피하고 핵심 키워드 중심
* 아이콘, 표, 카드, 화살표, 코드 블록, 체크리스트를 활용
* 실제 사람 사진은 사용하지 않음
* 전문적이지만 초보자도 이해하기 쉬운 시각 자료
* 각 이미지는 독립적인 PNG로 사용할 수 있게 구성

생성할 이미지는 총 5개입니다.

```text
LLM 코드 생성과 검증 전체 흐름도
```

이미지 내용:

LLM이 pandas 코드 초안을 생성하고 사람이 검증한 뒤 프로젝트에 반영하는 전체 흐름을 표현해 주세요.

포함할 단계:

1. 데이터 구조 요약

3. LLM 코드 초안 생성
4. 실행 전 검증
5. 코드 실행
6. 실행 후 결과 검증
7. 오류 수정
8. 검증된 코드 반영

* 중앙에는 “LLM 초안 ≠ 최종 코드” 메시지를 강조

하단 문구:

```text
LLM이 만든 코드는 실행 전후 검증을 거쳐야 프로젝트에 반영할 수 있습니다.
```

구성:

## 이미지 3

파일명:

```text
ch10_code_review_checklist.png
```

이미지 제목:

```text
LLM 생성 코드 리뷰 체크리스트
```

이미지 내용:

LLM이 생성한 pandas 코드를 검토할 때 확인해야 할 항목을 체크리스트 형태로 보여 주세요.

포함할 체크 항목:

1. 실제 컬럼명인가?
2. 병합 기준이 맞는가?
3. 날짜 변환이 필요한가?
4. 결측치 확인을 했는가?
5. 병합 후 행 수가 맞는가?
6. 집계 총합이 원본과 맞는가?
7. 정렬 기준이 맞는가?
8. 개인정보 노출은 없는가?
9. 코드가 실제로 실행되는가?

시각 구성:

* 큰 체크리스트 카드
* 각 항목 옆에 체크박스
* 위험 항목에는 작은 경고 아이콘
* 오른쪽에는 짧은 코드 블록 예시
* “실행 가능”과 “논리적으로 맞음”을 구분해서 표현

하단 문구:

```text
코드가 실행된다고 해서 분석 논리가 항상 맞는 것은 아닙니다.
```

캡션:

```text
그림 10-3. LLM 생성 코드 리뷰 체크리스트
```

## 공통 디자인 요구사항

모든 이미지는 다음 스타일을 유지해 주세요.

* 배경: 흰색
* 주요 색상: 네이비, 블루, 연한 하늘색
* 강조 색상: LLM은 보라색, 검증은 초록색, 오류와 주의사항은 주황색
* 글꼴 느낌: 깔끔한 고딕체
* 분위기: 대학교 강의 교재, 실무형 데이터 분석 교재
* 구성: 카드, 표, 화살표, 아이콘, 코드 블록, 체크리스트 중심
* 출력: PNG 이미지로 사용할 수 있는 선명한 고해상도
* 한국어 텍스트는 오탈자 없이 자연스럽게 표현

이미지 안에 너무 긴 문장은 넣지 말고, 핵심 키워드와 짧은 설명 중심으로 구성해 주세요.
