# Chapter 11 이미지 생성 프롬프트

LLM 기반 데이터 분석 실무 입문 교재의 Chapter 11 “분석 결과 해석과 인사이트 도출”에 사용할 교육용 인포그래픽 이미지를 생성해 주세요.

전체 이미지 스타일은 다음 기준을 따릅니다.

* 한국어 교재용 이미지
* 16:9 비율
* 흰색 배경
* 네이비/블루 계열 중심
* 깔끔한 교육용 슬라이드 스타일
* 분석 결과, 해석, 관찰, 가설, 인사이트, 실행 제안 흐름을 직관적으로 표현
* 너무 많은 텍스트는 피하고 핵심 키워드 중심
* 아이콘, 표, 카드, 화살표, 체크리스트를 활용
* 실제 사람 사진은 사용하지 않음
* 전문적이지만 초보자도 이해하기 쉬운 시각 자료
* 각 이미지는 독립적인 PNG로 사용할 수 있게 구성

생성할 이미지는 총 5개입니다.

## 이미지 1

파일명:

```text
ch11_interpretation_overview_flow.png
```

이미지 제목:

```text
분석 결과 해석과 인사이트 도출 전체 흐름도
```

이미지 내용:

분석 결과표와 그래프가 해석, 인사이트, 실행 제안으로 이어지는 전체 흐름을 표현해 주세요.

포함할 단계:

1. 분석 결과 확인
2. 지표 검증
3. 관찰 내용 작성
4. 의미 해석
5. 원인 가설 구분
6. 추가 분석 질문 도출
7. 인사이트 카드 작성
8. 보고서 반영

시각 구성:

* 왼쪽에서 오른쪽으로 흐르는 프로세스
* 표 아이콘, 그래프 아이콘, 돋보기 아이콘, 전구 아이콘, 보고서 아이콘 사용
* “관찰 → 해석 → 가설 → 인사이트 → 제안” 흐름 강조
* 하단에 핵심 문구 삽입

하단 문구:

```text
인사이트는 데이터 기반 관찰에서 시작해 추가 분석과 실행 제안으로 이어집니다.
```

캡션:

```text
그림 11-1. 분석 결과 해석과 인사이트 도출 전체 흐름도
```

## 이미지 2

파일명:

```text
ch11_observation_insight_action.png
```

이미지 제목:

```text
관찰·해석·가설·인사이트·실행 제안의 관계
```

이미지 내용:

분석 결과를 해석할 때 관찰, 해석, 가설, 인사이트, 실행 제안을 구분하는 구조를 표현해 주세요.

포함할 카드:

1. 관찰

   * 데이터에서 확인한 사실
   * 예: 전자기기 매출 비중 1위

2. 해석

   * 관찰의 의미
   * 예: 전체 매출에 크게 기여

3. 가설

   * 가능한 원인
   * 예: 판매 수량 또는 단가 영향 가능

4. 인사이트

   * 의사결정 메시지
   * 예: 매출 구조 분해 필요

5. 실행 제안

   * 다음 행동
   * 예: 수량·단가 추가 분석

시각 구성:

* 5단계 계단형 또는 화살표형 흐름
* 각 단계는 색상 구분 카드
* 관찰은 파란색, 가설은 보라색, 실행 제안은 초록색
* “원인 단정 금지” 주의 아이콘 포함

하단 문구:

```text
데이터로 확인한 사실과 가능한 원인 가설은 반드시 구분해야 합니다.
```

캡션:

```text
그림 11-2. 관찰·해석·가설·인사이트·실행 제안의 관계
```

## 이미지 3

파일명:

```text
ch11_evidence_validation_matrix.png
```

이미지 제목:

```text
분석 해석의 증거 수준 검증 매트릭스
```

이미지 내용:

분석 해석이 현재 데이터로 확인 가능한지 판단하는 매트릭스를 표현해 주세요.

구성:

3개 구역으로 나누어 표현:

1. 현재 데이터로 확인 가능

   * 카테고리별 매출
   * 월별 주문 수
   * 고객별 구매 금액

2. 추가 분석 필요

   * 매출 증가 원인
   * 판매 수량과 단가 영향
   * 반복 구매 여부

3. 현재 데이터로 판단 불가

   * 고객 선호도
   * 프로모션 효과
   * 고객 만족도
   * 이탈 원인

시각 구성:

* 3열 매트릭스 또는 신호등 구조
* 확인 가능은 초록색, 추가 분석 필요는 주황색, 판단 불가는 회색 또는 빨간색
* 각 구역에 체크, 물음표, 경고 아이콘 사용
* 분석 보고서 작성 전 검증표 느낌

하단 문구:

```text
현재 데이터로 확인 가능한 내용과 추가 데이터가 필요한 내용을 구분해야 합니다.
```

캡션:

```text
그림 11-3. 분석 해석의 증거 수준 검증 매트릭스
```

## 이미지 4

파일명:

```text
ch11_insight_card_structure.png
```

이미지 제목:

```text
인사이트 카드 구조
```

이미지 내용:

분석 결과를 인사이트 카드로 정리하는 템플릿 구조를 표현해 주세요.

카드에 포함할 항목:

1. 분석 질문
2. 핵심 지표
3. 관찰 결과
4. 해석
5. 가능한 가설
6. 추가 확인 사항
7. 다음 행동 제안

시각 구성:

* 중앙에 큰 카드 형태
* 각 항목을 섹션으로 구분
* 오른쪽에는 예시 미니 카드 표시

  * 분석 질문: 카테고리별 매출은?
  * 관찰: 전자기기 매출 비중 1위
  * 제안: 수량·단가 추가 분석
* 전구 아이콘, 체크리스트 아이콘, 보고서 아이콘 사용

하단 문구:

```text
인사이트 카드는 분석 결과를 보고서와 실행 제안으로 연결하는 도구입니다.
```

캡션:

```text
그림 11-4. 인사이트 카드 구조
```

## 이미지 5

파일명:

```text
ch11_llm_interpretation_review_flow.png
```

이미지 제목:

```text
LLM 해석 문장 검토 흐름도
```

이미지 내용:

LLM이 작성한 분석 해석 문장을 사람이 검토하고 안전한 문장으로 수정하는 과정을 표현해 주세요.

포함할 단계:

1. LLM 해석 문장 수신
2. 데이터 근거 확인
3. 원인 단정 표현 찾기
4. 추측 표현 찾기
5. 관찰과 가설 분리
6. 안전한 문장으로 수정
7. 보고서 반영

시각 구성:

* 왼쪽: LLM이 작성한 문장 카드

  * 예: “고객이 선호하기 때문입니다”
* 가운데: 검토 체크리스트

  * 근거 있음?
  * 원인 단정?
  * 추가 데이터 필요?
* 오른쪽: 수정된 안전한 문장 카드

  * 예: “추가 분석이 필요합니다”
* LLM은 보라색, 검증은 초록색, 위험 표현은 주황색으로 표시

하단 문구:

```text
LLM 해석은 자연스러워 보여도 데이터 근거를 기준으로 반드시 검토해야 합니다.
```

캡션:

```text
그림 11-5. LLM 해석 문장 검토 흐름도
```

## 공통 디자인 요구사항

모든 이미지는 다음 스타일을 유지해 주세요.

* 배경: 흰색
* 주요 색상: 네이비, 블루, 연한 하늘색
* 강조 색상: 인사이트는 초록색, 가설은 보라색, 주의사항은 주황색
* 글꼴 느낌: 깔끔한 고딕체
* 분위기: 대학교 강의 교재, 실무형 데이터 분석 교재
* 구성: 카드, 표, 화살표, 아이콘, 체크리스트 중심
* 출력: PNG 이미지로 사용할 수 있는 선명한 고해상도
* 한국어 텍스트는 오탈자 없이 자연스럽게 표현

이미지 안에 너무 긴 문장은 넣지 말고, 핵심 키워드와 짧은 설명 중심으로 구성해 주세요.
