## 이미지 2

파일명:

```text
ch05_raw_processed_structure.png
```

이미지 제목:

```text
raw 데이터와 processed 데이터 분리 구조
```

이미지 내용:

프로젝트 폴더에서 원본 데이터와 전처리된 데이터를 분리해서 관리하는 구조를 표현해 주세요.

표현할 폴더 구조:

```text
data/
├─ raw/
│  ├─ customers.csv
│  ├─ products.csv
│  ├─ orders.csv
│  └─ order_items.csv
└─ processed/
   ├─ customers_clean.csv
   ├─ products_clean.csv
   ├─ orders_clean.csv
   └─ order_items_clean.csv
```

시각 구성:

* 왼쪽: `data/raw` 폴더, “원본 데이터”
* 가운데: “전처리 과정” 화살표
* 오른쪽: `data/processed` 폴더, “정리된 데이터”
* raw 폴더는 수정하지 않는 원본 보관소로 표현
* processed 폴더는 분석에 사용할 정리된 데이터로 표현

하단 문구:

```text
원본 데이터는 보존하고, 전처리 결과는 별도 폴더에 저장합니다.
```

캡션:

```text
그림 5-2. raw 데이터와 processed 데이터 분리 구조
```

## 이미지 3

파일명:

```text
ch05_missing_duplicate_outlier.png
```

이미지 제목:

```text
결측치·중복·이상값 전처리 개념도
```

이미지 내용:

데이터 전처리에서 자주 만나는 세 가지 문제를 한 화면에 비교해서 보여 주세요.

세 영역으로 나누어 표현:

1. 결측치

   * 빈 셀 또는 NaN 표시
   * 처리 방법: 삭제, 대체, Unknown 처리

2. 중복 데이터

   * 같은 행이 반복되는 표
   * 처리 방법: 중복 확인, ID 기준 확인, 필요 시 제거

3. 이상값

   * 비정상적으로 큰 값 또는 음수 수량
   * 처리 방법: 확인, 보류, 수정, 제외

시각 구성:

* 3열 카드 레이아웃
* 각 카드에 작은 표 예시 포함
* 결측치는 빈 셀, 중복은 반복 행, 이상값은 빨간색 경고 표시
* 각 카드 하단에 “무조건 삭제하지 말고 의미를 먼저 확인” 메시지 포함

하단 문구:

```text
전처리 기준은 분석 목적과 데이터 의미를 함께 고려해 결정합니다.
```

캡션:


## 공통 디자인 요구사항

모든 이미지는 다음 스타일을 유지해 주세요.

* 배경: 흰색
* 주요 색상: 네이비, 블루, 연한 하늘색
* 강조 색상: 경고는 주황색 또는 빨간색, 정상 처리는 초록색
* 글꼴 느낌: 깔끔한 고딕체
* 분위기: 대학교 강의 교재, 실무형 데이터 분석 교재
* 구성: 표, 카드, 화살표, 아이콘 중심
* 출력: PNG 이미지로 사용할 수 있는 선명한 고해상도
* 한국어 텍스트는 오탈자 없이 자연스럽게 표현

이미지 안에 너무 긴 문장은 넣지 말고, 핵심 키워드와 짧은 설명 중심으로 구성해 주세요.
