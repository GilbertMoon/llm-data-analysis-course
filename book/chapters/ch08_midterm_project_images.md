# Chapter 8 이미지 생성 프롬프트

LLM 기반 데이터 분석 실무 입문 교재의 Chapter 8 “중간 실습 프로젝트”에 사용할 교육용 인포그래픽 이미지를 생성해 주세요.

전체 이미지 스타일은 다음 기준을 따릅니다.

* 한국어 교재용 이미지
* 16:9 비율
* 흰색 배경
* 네이비/블루 계열 중심
* 깔끔한 교육용 슬라이드 스타일
* 데이터 분석 프로젝트, pandas, 전처리, EDA, 시각화, 보고서 작성 흐름을 직관적으로 표현
* 너무 많은 텍스트는 피하고 핵심 키워드 중심
* 아이콘, 표, 카드, 화살표, 단계 박스를 활용
* 실제 사람 사진은 사용하지 않음
* 전문적이지만 초보자도 이해하기 쉬운 시각 자료
* 각 이미지는 독립적인 PNG로 사용할 수 있게 구성

생성할 이미지는 총 5개입니다.

## 공통 디자인 요구사항

모든 이미지는 다음 스타일을 유지해 주세요.

* 배경: 흰색
* 주요 색상: 네이비, 블루, 연한 하늘색
* 강조 색상: 질문은 보라색, 결과물은 초록색, 주의사항은 주황색
* 글꼴 느낌: 깔끔한 고딕체
* 분위기: 대학교 강의 교재, 실무형 데이터 분석 교재
* 구성: 카드, 표, 화살표, 아이콘, 단계 박스 중심
* 출력: PNG 이미지로 사용할 수 있는 선명한 고해상도
* 한국어 텍스트는 오탈자 없이 자연스럽게 표현

이미지 안에 너무 긴 문장은 넣지 말고, 핵심 키워드와 짧은 설명 중심으로 구성해 주세요.
