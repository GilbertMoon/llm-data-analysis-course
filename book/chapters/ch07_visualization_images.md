# Chapter 7 이미지 생성 프롬프트

LLM 기반 데이터 분석 실무 입문 교재의 Chapter 7 “데이터 시각화”에 사용할 교육용 인포그래픽 이미지를 생성해 주세요.

전체 이미지 스타일은 다음 기준을 따릅니다.

* 한국어 교재용 이미지
* 16:9 비율
* 흰색 배경
* 네이비/블루 계열 중심
* 깔끔한 교육용 슬라이드 스타일
* 데이터 분석, pandas, matplotlib, 그래프 선택, 시각화, 보고서 흐름을 직관적으로 표현
* 너무 많은 텍스트는 피하고 핵심 키워드 중심
* 아이콘, 표, 카드, 화살표, 간단한 그래프 예시를 활용
* 실제 사람 사진은 사용하지 않음
* 전문적이지만 초보자도 이해하기 쉬운 시각 자료
* 각 이미지는 독립적인 PNG로 사용할 수 있게 구성

생성할 이미지는 총 5개입니다.

## 이미지 2

파일명:

```text id="urcwia"
ch07_chart_selection_guide.png
```

이미지 제목:

```text id="cy3puy"
분석 질문별 그래프 선택 가이드
```

이미지 내용:

분석 질문에 따라 어떤 그래프를 선택해야 하는지 한 화면에 정리해 주세요.

표현할 매칭:

1. 범주별 크기 비교

   * 그래프: 막대그래프
   * 예: 카테고리별 매출

2. 시간 흐름 확인

   * 그래프: 선 그래프
   * 예: 월별 매출

3. 값의 분포 확인

   * 그래프: 히스토그램
   * 예: 상품 가격 분포

4. 두 변수 관계 확인

   * 그래프: 산점도
   * 예: 가격과 판매 수량 관계

5. 상위 항목 비교

   * 그래프: 가로 막대그래프
   * 예: 구매 금액 상위 고객

시각 구성:

* 5개 카드 또는 5행 비교표
* 각 카드에 작은 그래프 아이콘 포함
* 막대, 선, 히스토그램, 산점도, 가로 막대 아이콘을 명확히 구분
* 초보자가 한눈에 그래프 선택 기준을 이해할 수 있게 구성

하단 문구:

```text id="99gqib"
좋은 시각화는 분석 질문에 맞는 그래프 선택에서 시작됩니다.
```

이미지 내용:

* Figure
* Plot area
* Title
* x-axis

* data points or bars

시각 구성:

* 중앙에 간단한 막대그래프 또는 선 그래프 예시

코드 흐름 카드:

```text id="xx882x"

plt.bar() 또는 plt.plot()

plt.xlabel()
plt.ylabel()
plt.tight_layout()
plt.savefig()
plt.show()
```


## 공통 디자인 요구사항

모든 이미지는 다음 스타일을 유지해 주세요.

* 배경: 흰색
* 주요 색상: 네이비, 블루, 연한 하늘색
* 강조 색상: 질문은 보라색, 주의사항은 주황색, 정상 흐름은 초록색
* 글꼴 느낌: 깔끔한 고딕체
* 분위기: 대학교 강의 교재, 실무형 데이터 분석 교재
* 구성: 카드, 표, 화살표, 아이콘, 간단한 그래프 중심
* 출력: PNG 이미지로 사용할 수 있는 선명한 고해상도
* 한국어 텍스트는 오탈자 없이 자연스럽게 표현

이미지 안에 너무 긴 문장은 넣지 말고, 핵심 키워드와 짧은 설명 중심으로 구성해 주세요.
