# Chapter 9 이미지 생성 프롬프트

LLM 기반 데이터 분석 실무 입문 교재의 Chapter 9 “LLM 프롬프트 기반 분석 보조”에 사용할 교육용 인포그래픽 이미지를 생성해 주세요.

전체 이미지 스타일은 다음 기준을 따릅니다.

* 한국어 교재용 이미지
* 16:9 비율
* 흰색 배경
* 네이비/블루 계열 중심
* 깔끔한 교육용 슬라이드 스타일
* 데이터 분석, LLM, 프롬프트, pandas, 검증, 보고서 작성 흐름을 직관적으로 표현
* 너무 많은 텍스트는 피하고 핵심 키워드 중심
* 아이콘, 표, 카드, 화살표, 단계 박스를 활용
* 실제 사람 사진은 사용하지 않음
* 전문적이지만 초보자도 이해하기 쉬운 시각 자료
* 각 이미지는 독립적인 PNG로 사용할 수 있게 구성

생성할 이미지는 총 5개입니다.

파일명:

```text

```

이미지 제목:

```text
LLM 기반 데이터 분석 보조 흐름도
```

이미지 내용:

LLM이 데이터 분석 과정에서 보조 역할을 하는 전체 흐름을 표현해 주세요.

포함할 단계:

1. 데이터 구조 요약
2. 프롬프트 작성
3. LLM 코드 초안 생성
4. 사람이 코드 검증
5. 코드 실행
6. 결과 해석 요청
7. 사람이 해석 검증
8. 보고서 반영

시각 구성:

* 왼쪽에서 오른쪽으로 흐르는 프로세스
* LLM은 중앙의 보조 도구로 표현
* DataFrame, 프롬프트, 코드, 체크리스트, 보고서 아이콘 사용
* “LLM 초안”과 “사람 검증”을 색상으로 구분
* 하단에 핵심 문구 삽입

하단 문구:

```text
LLM은 분석을 대신하는 도구가 아니라, 사람이 검증해야 하는 분석 보조 도구입니다.
```

캡션:

```text
그림 9-1. LLM 기반 데이터 분석 보조 흐름도
```

## 이미지 2

파일명:

```text
ch09_prompt_structure.png
```

이미지 제목:

```text
데이터 분석 프롬프트 구조
```

이미지 내용:

좋은 데이터 분석 프롬프트가 어떤 요소로 구성되는지 보여 주세요.

포함할 요소:

1. 역할

   * 데이터 분석 강사
   * pandas 코드 도우미

2. 목적

   * 카테고리별 매출 계산
   * 월별 매출 분석

3. 데이터 구조

   * 데이터셋 이름
   * 컬럼명
   * shape

4. 요청 작업

   * merge
   * groupby
   * 시각화
   * 해석

5. 제약 조건

   * 추측 금지
   * 실제 컬럼명만 사용
   * 초보자용 설명

6. 출력 형식

   * 코드
   * 표
   * 보고서 문장
   * 체크리스트

시각 구성:

* 중앙에 “좋은 프롬프트” 카드
* 주변에 6개 구성 요소 카드 배치
* 각 카드에 짧은 예시 문구 포함
* 프롬프트 문서와 체크리스트 느낌

하단 문구:

```text
좋은 프롬프트는 역할, 목적, 데이터 구조, 요청 사항, 제약 조건을 함께 포함합니다.
```

캡션:

```text
그림 9-2. 데이터 분석 프롬프트 구조
```

## 공통 디자인 요구사항

모든 이미지는 다음 스타일을 유지해 주세요.

* 배경: 흰색
* 주요 색상: 네이비, 블루, 연한 하늘색
* 강조 색상: LLM은 보라색, 검증은 초록색, 주의사항은 주황색
* 글꼴 느낌: 깔끔한 고딕체
* 분위기: 대학교 강의 교재, 실무형 데이터 분석 교재
* 구성: 카드, 표, 화살표, 아이콘, 체크리스트 중심
* 출력: PNG 이미지로 사용할 수 있는 선명한 고해상도
* 한국어 텍스트는 오탈자 없이 자연스럽게 표현

이미지 안에 너무 긴 문장은 넣지 말고, 핵심 키워드와 짧은 설명 중심으로 구성해 주세요.
