# 0장. 이 책의 방향과 전체 흐름

데이터 분석을 배운다는 것은 pandas 문법을 외우거나 그래프 몇 개를 그리는 일에 머물지 않습니다. 실제 분석 프로젝트에서는 데이터를 이해하고, 정리하고, 질문을 만들고, 지표를 계산하고, 결과를 해석해야 합니다. 여기에 머신러닝, LLM, 외부 데이터, 자동화 도구까지 연결되면 하나의 실무형 분석 흐름이 만들어집니다.

이 책은 그 흐름을 처음부터 끝까지 자연스럽게 경험하기 위한 입문형 ebook입니다. Python과 VS Code를 기반으로 분석 환경을 준비하고, pandas와 시각화로 데이터를 탐색한 뒤, 회귀와 분류 모델링으로 예측 분석의 기본을 살펴봅니다. 이후에는 LLM을 분석 질문 정리, 코드 초안 작성, 코드 검증, 결과 해석의 보조 도구로 활용하고, 외부 데이터 수집과 자동화 파이프라인으로 프로젝트를 확장합니다.

이 책에서 강조하는 관점은 분명합니다. AI가 분석을 대신하는 것이 아니라, **사람이 분석 목적과 판단 기준을 세우고, AI와 자동화 도구를 활용해 반복 작업과 초안 작성의 효율을 높이는 것**입니다. LLM이 만든 코드와 문장은 항상 사람이 검토해야 하며, 데이터에 없는 원인을 단정하지 않는 태도가 중요합니다.

## 1. 이 책에서 다루는 분석 흐름

이 책의 전체 흐름은 하나의 데이터 분석 프로젝트가 점점 확장되는 과정과 비슷합니다.

먼저 AI 시대의 데이터 분석을 어떤 관점으로 바라볼지 정리하고, VS Code 중심의 Python 분석 환경을 준비합니다. 그다음 CSV 파일의 구조를 이해하고, pandas로 데이터에 질문을 던지며, 결측치와 중복, 타입 문제를 전처리합니다. 이어서 EDA 질문을 만들고, 시각화로 결과를 더 직관적으로 확인합니다. 중간 프로젝트에서는 지금까지의 내용을 하나의 작은 분석 프로젝트로 묶어 봅니다.

후반부에서는 머신러닝으로 넘어갑니다. 회귀 분석에서는 숫자를 예측하고, 분류 분석에서는 범주를 예측합니다. 이후 LLM을 활용해 분석 질문을 다듬고, LLM이 만든 분석 코드를 검증하는 방법을 다룹니다. 마지막으로 공공데이터, 네이버 API, 크롤링을 통해 외부 데이터로 분석을 확장하고, Make, n8n, Airflow를 활용해 반복되는 분석 흐름을 자동화하는 방법을 살펴봅니다.

## 4. LLM을 사용하는 관점

이 책에서 LLM은 분석을 대신 수행하는 존재가 아닙니다. LLM은 다음 작업을 도와주는 보조 도구입니다.

- 분석 질문을 더 구체적인 지표로 바꾸기
- 데이터 구조를 설명 가능한 형태로 정리하기
- pandas 코드 초안 작성하기
- 오류 메시지의 원인 설명하기
- 시각화 코드나 모델링 코드의 구조 제안하기
- 보고서 문장을 더 자연스럽게 다듬기
- 코드와 해석에서 빠진 검증 항목 찾기

하지만 LLM의 답변은 항상 검증해야 합니다. 데이터에 없는 컬럼명을 만들거나, 원인을 단정하거나, 모델 평가 지표를 잘못 선택할 수 있습니다. 특히 개인정보, API Key, 내부 데이터, 민감한 파일 경로는 LLM 프롬프트에 포함하지 않아야 합니다.

이 책은 각 장을 따로 읽어도 되지만, 전체적으로는 하나의 프로젝트가 점점 확장되는 흐름으로 읽는 것이 좋습니다.

처음에는 온라인 쇼핑몰 데이터를 사용해 고객, 상품, 주문, 매출을 이해합니다. 중간 프로젝트에서는 이 데이터를 바탕으로 기본 분석 보고서를 완성합니다. 후반부에는 이 데이터를 회귀와 분류 문제로 확장하고, LLM을 활용해 분석 질문과 코드를 검토하며, 외부 데이터와 자동화 도구를 연결해 더 실무적인 프로젝트 구조로 발전시킵니다.

따라서 각 장의 목표는 단순히 기능 하나를 익히는 것이 아니라, 다음 질문에 답할 수 있는 분석 흐름을 만드는 것입니다.

```text

그 결과를 어떤 코드와 지표로 확인할 수 있는가?
해석할 때 조심해야 할 점은 무엇인가?
LLM이나 자동화 도구를 어디까지 활용할 수 있는가?
최종 판단은 어떤 근거로 사람이 내려야 하는가?
```

이 책을 끝까지 따라가면 간단한 데이터 분석 프로젝트를 스스로 구성할 수 있습니다. 원본 데이터를 불러오고, 구조를 확인하고, 전처리하고, EDA 질문을 만들고, 시각화와 기본 머신러닝 모델을 적용한 뒤, LLM과 자동화 도구를 보조적으로 활용하는 흐름을 경험하게 됩니다.
