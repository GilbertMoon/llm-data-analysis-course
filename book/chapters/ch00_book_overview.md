# 0장. 이 책의 방향과 전체 흐름

데이터 분석을 배운다는 것은 단순히 pandas 문법을 익히거나 그래프를 그리는 방법을 외우는 일이 아닙니다. 실제 분석 프로젝트에서는 데이터를 이해하고, 정리하고, 질문을 만들고, 지표를 계산하고, 결과를 해석하고, 필요한 경우 머신러닝과 LLM, 외부 데이터, 자동화 도구까지 함께 연결해야 합니다.

이 책은 그런 흐름을 한 번에 완성하기 위한 입문형 ebook입니다. Python과 VS Code를 기반으로 데이터 분석의 기본기를 다지고, pandas와 시각화로 데이터를 탐색한 뒤, 회귀와 분류 모델링을 통해 머신러닝의 기본 흐름을 경험합니다. 이후에는 LLM을 분석 질문 정리, 코드 초안 작성, 결과 검토의 보조 도구로 활용하고, 공공데이터·API·크롤링과 자동화 파이프라인으로 분석 프로젝트를 확장합니다.

핵심은 AI가 분석을 대신하게 만드는 것이 아닙니다. **사람이 분석의 목적과 판단 기준을 세우고, AI와 자동화 도구를 활용해 반복 작업과 초안 작성의 효율을 높이는 것**입니다. LLM이 만든 코드와 문장은 항상 사람이 검토해야 하며, 데이터에 없는 원인을 단정하지 않는 태도가 중요합니다.

## 1. 이 책에서 다루는 분석 흐름

이 책의 전체 흐름은 하나의 데이터 분석 프로젝트가 확장되는 과정과 비슷합니다.

처음에는 개발 환경을 준비하고, CSV 파일의 구조를 이해합니다. 이어서 pandas로 데이터를 다루고, 결측치와 중복, 타입 문제를 전처리합니다. 그다음 EDA 질문을 만들고, 시각화로 결과를 더 직관적으로 확인합니다. 중간 프로젝트에서는 지금까지의 내용을 하나의 작은 분석 프로젝트로 묶어 봅니다.

후반부에서는 머신러닝으로 넘어갑니다. 회귀 분석에서는 숫자를 예측하고, 분류 분석에서는 범주를 예측합니다. 이후 LLM을 활용해 분석 질문을 정리하고, 코드 초안을 만들고, 그 코드를 검증하는 방법을 다룹니다. 마지막으로 외부 데이터 수집과 자동화 파이프라인을 통해 분석 프로젝트를 더 실제 업무에 가까운 형태로 확장합니다.

## 4. LLM을 사용하는 관점

이 책에서 LLM은 분석을 대신 수행하는 존재가 아닙니다. LLM은 다음 작업을 도와주는 보조 도구입니다.

- 분석 질문을 더 구체적인 지표로 바꾸기
- pandas 코드 초안 작성하기
- 오류 메시지의 원인 설명하기
- 시각화 코드나 모델링 코드의 구조 제안하기
- 보고서 문장을 더 자연스럽게 다듬기
- 코드와 해석에서 빠진 검증 항목 찾기

하지만 LLM의 답변은 항상 검증해야 합니다. 데이터에 없는 컬럼명을 만들거나, 원인을 단정하거나, 모델 평가 지표를 잘못 선택할 수 있습니다. 특히 개인정보, API Key, 내부 데이터, 민감한 파일 경로는 LLM 프롬프트에 포함하지 않아야 합니다.
