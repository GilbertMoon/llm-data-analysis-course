# Chapter 6 이미지 생성 프롬프트

LLM 기반 데이터 분석 실무 입문 교재의 Chapter 6 “EDA와 분석 질문 만들기”에 사용할 교육용 인포그래픽 이미지를 생성해 주세요.

전체 이미지 스타일은 다음 기준을 따릅니다.

* 한국어 교재용 이미지
* 16:9 비율
* 흰색 배경
* 네이비/블루 계열 중심
* 깔끔한 교육용 슬라이드 스타일
* 데이터 분석, pandas, EDA, 분석 질문, 지표 설계, 보고서 흐름을 직관적으로 표현

* 아이콘, 표, 카드, 화살표, 단계 박스를 활용
* 실제 사람 사진은 사용하지 않음
* 전문적이지만 초보자도 이해하기 쉬운 시각 자료


이미지 제목:

```text

```

이미지 내용:

모호한 분석 질문을 구체적인 지표와 pandas 코드로 바꾸는 과정을 표현해 주세요.

예시 흐름:

```text
어떤 상품이 잘 팔리는가?
→ 카테고리별 총매출은 얼마인가?
→ 필요한 데이터: order_items + products
→ 지표: total_sales, sales_ratio
→ pandas 기능: merge(), groupby(), sum()
```

시각 구성:

* 왼쪽: 모호한 질문 카드
* 가운데: 구체화 단계 카드
* 오른쪽: 지표와 코드 카드
* 화살표로 연결
* 질문 아이콘, 테이블 아이콘, 코드 아이콘 사용
* 하단에 “좋은 질문은 계산 가능한 지표로 바뀌어야 합니다.” 문구 삽입

하단 문구:

```text
좋은 분석 질문은 데이터와 지표로 검증할 수 있어야 합니다.
```


## 이미지 3

파일명:

```text
ch06_eda_types.png
```

이미지 제목:

```text
단변량·이변량·다변량 EDA 비교
```

이미지 내용:

단변량 EDA, 이변량 EDA, 다변량 EDA의 차이를 한 화면에서 비교해 주세요.

세 영역으로 나누어 표현:

1. 단변량 EDA

   * 하나의 변수 확인
   * 예: 고객 나이 분포, 카테고리별 상품 수

2. 이변량 EDA

   * 두 변수의 관계 확인
   * 예: 카테고리별 매출, 월별 주문 수

3. 다변량 EDA

   * 여러 변수의 관계 확인
   * 예: 월별·카테고리별 매출, 지역별·연령대별 구매 금액

시각 구성:

* 3열 카드 레이아웃
* 각 카드에 작은 표 또는 간단한 그래프 아이콘 포함
* 단변량은 막대 1개 그룹, 이변량은 그룹별 비교, 다변량은 피벗 테이블 느낌
* 너무 복잡하지 않게 구성

하단 문구:

```text
EDA는 변수의 개수와 분석 목적에 따라 탐색 방식이 달라집니다.
```

캡션:

```text
그림 6-3. 단변량·이변량·다변량 EDA 비교
```

## 공통 디자인 요구사항

모든 이미지는 다음 스타일을 유지해 주세요.

* 배경: 흰색
* 주요 색상: 네이비, 블루, 연한 하늘색
* 강조 색상: 질문은 보라색, 주의사항은 주황색, 정상 흐름은 초록색
* 글꼴 느낌: 깔끔한 고딕체
* 분위기: 대학교 강의 교재, 실무형 데이터 분석 교재
* 구성: 카드, 표, 화살표, 아이콘 중심
* 출력: PNG 이미지로 사용할 수 있는 선명한 고해상도
* 한국어 텍스트는 오탈자 없이 자연스럽게 표현

이미지 안에 너무 긴 문장은 넣지 말고, 핵심 키워드와 짧은 설명 중심으로 구성해 주세요.
