# Overview 공개 이미지 자산

이 폴더는 Overview(0장) 블로그와 학생 실습 문서에서 사용할 공개 이미지 자산을 관리합니다.

## 기준 썸네일

권장 파일명:

```text
overview_course_roadmap.png
```

규격:

```text
1536 × 1024
3:2
PNG 또는 JPG 우선
```

내용 기준:

```text
AI와 함께하는 데이터 분석 전체 여정
질문 정의 → 데이터 준비 → 탐색적 분석 → 모델링 → 검증 → 자동화 → 의사결정
Chapter 01 ~ Chapter 15 로드맵
가상 쇼핑몰 데이터 4종
Python·Jupyter·Airflow·LLM 등 주요 도구
Public 실습 저장소 안내
```

블로그 연결용 Public raw URL은 다음 형식을 사용합니다.

```text
https://raw.githubusercontent.com/GilbertMoon/llm-data-analysis-course/main/book/assets/images/overview/overview_course_roadmap.png
```

## 사용 규칙

- Private 저장소 URL을 사용하지 않습니다.
- token이 포함된 URL을 사용하지 않습니다.
- 블로그에서는 PNG/JPG를 우선 사용합니다.
- 실제 이미지 파일이 존재하는지 확인한 뒤 블로그 원고에 연결합니다.
- 이미지 내용은 `0장. 이 책의 방향과 전체 흐름` 본문과 다시 대조합니다.
